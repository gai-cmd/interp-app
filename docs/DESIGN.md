# DESIGN.md · 실시간 통역 (Interp App)

브랜드 중립·접근성 우선. 통역은 "듣고 말하는 순간"의 도구라서 화면은 조용하고, 큰 글자, 큰 버튼, 상태가 한눈에 보여야 한다. 모바일이 1순위, 태블릿·데스크톱은 같은 부품을 넓게 배치한다.

## 1. 분위기
- 차분한 남색 악센트 + 밝은 회색 바탕(다크 모드는 진한 청회색). 장식 없음, 그림자 최소.
- 정보 밀도 낮게: 한 화면에 "지금 할 일" 하나(말하기 / 듣기).
- 상태는 색이 아니라 **텍스트+아이콘+속성**으로(색약·강제 색상 대응).

## 3. 타이포그래피
- 폰트: `-apple-system, "Segoe UI", Roboto, "Noto Sans KR", "Noto Sans JP", "Helvetica Neue", Arial, sans-serif` (시스템 우선 · 웹폰트 로드 없음 · 한·일 글리프는 OS 폰트).
- 크기(rem, 사용자 확대 존중): 본문 1rem(16px) · 보조 0.875rem · 라벨 0.8125rem(600) · 제목 1.25rem(700) · 앱 제목 1.125rem(700) · **자막/번역문 1.25rem(모바일)–1.5rem(태블릿+)**, 동시통역 자막은 사용자 조절(가+/가−, 1–2rem).
- 줄 간격 1.5, 단락 간격 0.5rem. 숫자·코드는 `ui-monospace`.

## 4. 컴포넌트
- **버튼**: 높이 ≥44px, 모서리 0.75rem, 글자 600. 종류: 주(accent 채움), 보조(surface-alt 채움·border), 위험(danger 채움), 텍스트형(밑줄 없음·accent 글자). 비활성은 투명도 .5가 아니라 `--surface-alt`+`--text-muted`. 로딩은 텍스트("통역 중…")로.
- **PTT(누르고 말하기)**: 전폭, 높이 64px(모바일)·56px(데스크톱), 누르는 동안 `--recording` 테두리 3px + 텍스트 "녹음 중" + 레벨 미터.
- **입력**: 높이 ≥44px, 테두리 1px `--border`, 포커스 시 `--focus` 링. select는 네이티브 유지(모바일 휠).
- **탭**: 상단 세그먼트, 활성 = accent 밑줄 3px + 굵게. `aria-selected` 필수.
- **배지**: 캡슐, 0.8125rem, 상태별 텍스트(키 없음 / 개인 키 / 현장 공용 키 / 연결됨 / 녹음 중).
- **카드**: `--surface`, 테두리 1px, 모서리 1rem, 패딩 1rem(모바일)·1.25rem(태블릿+), 그림자 없음(다이얼로그만 `0 12px 32px rgba(0,0,0,.18)`).
- **말풍선(순차)**: 원문은 `--surface-alt`, 번역은 `--accent-soft`; 좌측 2px 바로 화자 구분; 시각·엔진·지연은 0.8125rem muted; 행동 버튼(재생/기기 음성/재시도)은 말풍선 하단 우측 정렬.
- **동시통역 자막판**: 검은 배경 옵션(강당용 고대비) · 진행 중 문장은 muted, 확정은 본색 · 누락은 "…" + 경고 배지.
- **다이얼로그/설정**: 모바일 = 전체 화면 시트(상단 제목 + 닫기, 내용 스크롤, 하단 고정 행동), 태블릿+ = 중앙 모달 최대 640px. `inert`·포커스 트랩·Escape.
- **알림(notice)**: 상단 배너, 8초 자동 소거 + 닫기, 역할 `status`.
- **헤더**: 좌 앱 이름 · 중앙(데스크톱) 탭 · 우 배지 + **언어 토글(KO·EN·JA)** + 공유(QR) + 설정. 모바일은 탭을 헤더 아래 줄로.

## 5. 레이아웃
- 간격 스케일: 0.25 / 0.5 / 0.75 / 1 / 1.5 / 2 / 3rem.
- **모바일(<40rem)**: 1열, 좌우 패딩 1rem, 카드 전폭, 하단 안전영역(`env(safe-area-inset-bottom)`) 존중, PTT는 엄지 범위(화면 하단 1/3)에.
- **태블릿(40–64rem)**: 본문 최대 40rem 중앙; 설정은 2열 그리드(언어 | 키), 동시통역은 자막판 + 컨트롤 측면.
- **데스크톱(≥64rem)**: 최대 60rem; 순차통역은 좌 컨트롤(24rem) + 우 대화 기록(가변); 동시통역은 자막판 전폭 + 우측 상태 패널.
- 세로 리듬: 섹션 사이 1.5rem, 카드 내부 0.75rem.

## 6. 깊이
- 평면. 계층은 배경(`--bg`) → 카드(`--surface`) → 다이얼로그(그림자)로만.
- 상호작용 피드백은 색 변화 + 1px 테두리, 애니메이션은 150ms `ease-out`(reduced-motion 시 0).

## 7. 해야/하지 말아야
- 해야: 모든 문구 i18n 키 · 44px 터치 · `textContent` · 포커스 가시 · 상태 텍스트 · 다크 모드 토큰 · 한 화면 한 과제.
- 하지 말아야: 색만으로 상태 표현 · 웹폰트 로드 · 고정 px 글자 · 스크롤 잠금 · 자동 재생 소리 · 화면 문구 하드코딩 · innerHTML.

## 8. 반응형 규칙
- 브레이크포인트: 40rem(640px), 64rem(1024px). `min-width` 기준으로만.
- 가로 스크롤 금지. 긴 URL·키는 `overflow-wrap:anywhere`.
- 터치 우선: hover 효과는 `@media (hover:hover)` 안에만.
- 화면 회전·키보드 등장 시 PTT와 입력창이 항상 보이도록 하단 고정 영역(`position:sticky; bottom`).
- 데스크톱에서도 키보드만으로 전 흐름 조작 가능(Tab 순서 = 시각 순서).

## 9. 에이전트 지침
- 새 화면을 만들 때: 이 문서의 토큰·컴포넌트 이름(`.btn`, `.btn-primary`, `.card`, `.badge`, `.sheet`, `.tabs`)만 쓰고 새 색을 만들지 않는다.
- 문구는 `app/i18n/*.json`에 세 언어 동시 추가.
- 변경 후 확인: 430px·768px·1280px 세 폭에서 가로 스크롤 없음, 버튼 44px, 다크 모드, 포커스 링.
