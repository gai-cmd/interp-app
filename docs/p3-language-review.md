# P3-37 세 언어 전체 문구 검토 (2026-09-06)

기준: [design-p3.md](design-p3.md) §1.11·§1.12·§1.13·§1.14, [p3-verification.md](p3-verification.md) V13.

## 0. 이 문서가 주장하는 것과 주장하지 않는 것

**키 수 일치는 검토가 아니다.** `check-i18n`은 세 언어의 키 집합·placeholder·사용 여부만 본다.
그것은 통과해도 어색한 번역, 용어 불일치, 뜻이 어긋난 문장은 그대로 남는다.
이 문서는 사람이 세 언어를 통독하며 고친 것과, **고치지 못하고 남긴 것**을 적는다.

이 검토는 화면에서 실제로 읽어 본 것이 아니라 사전 통독이다.
실기기에서 줄바꿈·잘림·문맥을 확인하는 V13은 여전히 **미검증**이다.

## 1. 언어별 통독 결과

### 한국어

- 문체는 해요체로 일관. 명령형("확인하세요")은 사용자가 직접 해야 하는 동작에만 사용.
- 고친 것
  - `sim.twoWay.hint` — "서로 반대 언어로 통역해요"는 직역투였다. "들린 언어를 나머지 한 언어로 통역해요"로 바꿔 실제 동작을 말하게 했다.
  - `sim.modelDiscovered` — `“{model}”을(를)` 형태의 조사 병기는 기계 출력처럼 읽힌다. 조사가 필요 없도록 문장을 재구성했다.
  - `voice.previewNotOutput` — "그래도 들려줘요"가 주변 문장보다 과하게 구어체였다. "그대로 들을 수 있어요"로.
- 용어 규칙 (회귀 테스트로 고정)
  - **기기** = 사용자가 든 단말. **장치** = 마이크·스피커 같은 오디오 장치.
  - **통역**이 앱의 동작이고, **번역**은 자막·텍스트 결과를 가리킬 때만 쓴다.

### English

- 고친 것
  - `device.outputApplying` — 사전 전체에서 유일한 말줄임표(`…`)였다. 문체를 맞춰 제거.
  - `sim.twoWay.hint` — "renders each into the other"는 두 방향을 동시에 하는 것처럼 읽혔다.
    "renders whichever is spoken into the other"로 바꿔 발화 단위로 방향이 정해짐을 분명히 했다.
  - `sim.modelDiscovered` — 문장을 라벨 형태로 바꿔 모델 ID가 문장 중간에 끼지 않게 했다.

### 日本語

- **가장 많은 문제가 있던 언어.** 장치를 가리키는 말이 셋으로 갈려 있었다.
- 고친 것
  - `sim.twoWay.sameLanguage` — 「別々に選んでください」는 "따로따로 고르라"는 뜻으로, "서로 다른 언어를 고르라"가 아니었다. **오역**. 「異なる言語を選んでください」로 수정.
  - `device.outputApplying` / `device.outputApplied` — 「デバイス」를 썼으나 오디오 장치의 정착 용어는 「機器」다.
  - `device.deviceSpeechSystemOutput` — 「端末の音声」이 진단 화면의 「デバイス音声」와 어긋났다.
  - `diagnostics.metrics` — 「このデバイス」는 단말을 뜻하므로 「この端末」로.
  - `sim.error.MICROPHONE_UNAVAILABLE` — 「入力デバイス」를 「入力機器」로.
  - `hub.deviceSpeech` — 「デバイスの音声」를 고정 용어 「デバイス音声」로.
  - `sim.twoWay.oneVoice` — 「声は一つです」가 "목소리가 하나뿐"으로 읽혀 「使える声は一つです」로.
- 용어 규칙 (회귀 테스트로 고정)
  - **端末** = 사용자 단말. **機器** = 오디오 장치. **デバイス**는 「デバイス音声」(기기 음성) 안에서만.

## 2. 세 언어 공통으로 지킨 약속

아래는 문구가 앱의 실제 동작보다 많은 것을 약속하지 않도록 지키는 문장들이며, 회귀 테스트가 존재를 단언한다.

| 키 | 지키는 것 |
|---|---|
| `keyGuide.notAllFree` | 키 발급이 무료여도 모든 모델 사용이 무료는 아니다 |
| `billing.displayOnly` | Paid 선택은 표시 방식일 뿐, 결제를 켜지 않는다 |
| `billing.notZero` | 알 수 없는 비용을 0으로 표시하지 않는다 |
| `billing.estimateAlways` | 비용은 항상 추정이다 |
| `permission.gestureOnly` | 앱이 스스로 권한을 허용하거나 거부를 풀 수 없다 |
| `permission.notEvidence` | 과거 기록은 현재 권한의 근거가 아니다 |
| `admin.export.notPublished` | 다운로드는 발행이 아니다 |

## 3. 남은 미검증

- **V13(실기기 통독)** — 이 검토는 사전 통독이다. 실제 화면에서 줄바꿈·잘림·문맥을 본 것이 아니다.
- **제공자 UI 문구** — 권한 안내(`permission.help.*`)의 메뉴 이름은 iOS·Android·데스크톱 버전에 따라 달라진다.
  `permission.help.menuVaries`로 그 사실을 밝혀 두었으나, **실제 지원 버전에서의 확인은 오케스트레이터 몫**이며 아직 하지 않았다.
- **일본어 경어 수준** — 「ます」체로 통일돼 있으나, 행사 현장의 청중 대상 문구로 적절한지는 현장 확인이 필요하다.
